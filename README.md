# visualz

Audio-reactive generative visuals for live band shows, built to run on a Raspberry Pi plugged into a projector.

- Listens to a USB mic or line-in and drives evolving visuals from the music
- Multiple visual modes (8-bit pixel, kaleidoscope, sacred geometry, liquid light, op-art, chromascope, and a picture-morphing gallery), with pixel and halftone looks with auto-cycling
- MTV-style overlay: corner logo bug (image or looping video) and band/song titles, saved as switchable JSON templates
- Web UI on your phone or laptop to control everything live
